Install on Mac
  1. Open the DMG. Drag the AU, VST3 or app across its lane to the matching folder.
  2. Prefer personal folders without an admin password? Open Easy Install instead. Choose one installation method.
  3. Restart or rescan your DAW, then find Pixel Records → Titty Tweeter.
Install on Windows
  1. Unzip the download.
  2. Copy the whole Titty Tweeter.vst3 folder to C:\Program Files\Common Files\VST3. Administrator approval may be needed.
  3. Restart or rescan your DAW’s VST3 plugins. The included README also explains personal folder installation.
Compatibility & what’s tested

Mac: Apple Silicon, macOS 12 or later build target; AUv2 + VST3. Windows: x64 VST3, built on Windows Server 2022. Mono or stereo, zero reported latency. Mac AU passes Apple’s strict validator. Both VST3 builds pass compiled-plugin host tests and pluginval at strictness 5. Windows automation and session restore are checked in CI. Individual DAWs and older OS versions still need broader testing. Intel Mac, VST2, 32-bit Windows and native Windows ARM builds are not included.

On a full mix, cymbals and bright synths can trigger the de-esser too. LISTEN REMOVED auditions removed audio. No limiter is included.
